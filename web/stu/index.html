How to read this

Scoring: a deal is bid once by the common bidder and played twice with the two bots' seats swapped, so both tables play the same contract and the IMPs are card play. One board per deal family per cell; boards played under an old id of the same bot count once. Pairing across cells uses the deal family. Rows are read from the loop's transfer branches (one row a board, published every ten minutes); the page re-reads runs that are still going every five minutes. Snapshot built by web/stu/build.cjs; registry of generations and bots in registry.json beside this page.
