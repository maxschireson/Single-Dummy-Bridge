# Diagnostic adapter v2

This isolated adapter imports the actual frozen runtime validator, receipt builder, state helper and dashboard exporter. It uses archived 65a fixtures 1600 (self), 2561 (BEN), 1601 (self), preserving their episode and receipt bytes. BEN post-state is a prior diagnostic RNG fixture, not a state produced by those archived episodes. There are zero production commits and no claim of recovering the dead server's RNG.

A writer lock protects immutable generations and a CURRENT marker with a linked previous marker, pre/post RNG hashes and per-file hashes. Normal commits copy the accepted BEN state; BEN commits require a supplied post-state. Duplicate indices and stale pre-state are rejected. Recovery follows only the hash-verified committed chain; orphan episodes are excluded. Materialization exposes only the accepted episode set to the existing exporter, with pinned retained receipt bytes unchanged. Copy/restore of the journal preserves exported counts, statistics, allocation, identity and final RNG state.

Actual SIGKILL tests exercise ten boundaries for BEN and normal commits: mkdir, episode, receipt, RNG, manifest, generation fsync, parent fsync, temporary marker fsync, pointer replacement and final fsync. Recovery and the actual exporter must agree on the old or new complete record set and RNG state. This tests process loss, not power loss.
