## Records, timing and recovery

The live run is `/workspace/work/gen5-codex-32`. Each completed deal is an atomic
`episodes/*.json.gz` with a checksum receipt in `receipts/`. Records contain
full legal trajectories, per-action PIMC estimates and final trick counts.
Historical/control games retain the prior fork-audit recipe; BEN benchmark
games have no training forks. Score and replay exports verify receipt hashes
and reconstruct recorded plays before publishing.

Publication branch `arena-gen5-codex-32-feed` holds minute-by-minute scores and
replays in `arena/`, plus the full manifest, corpus, model artifacts, raw episodes,
receipts and frozen runtime in `recovery/`. No training is launched automatically.
The publisher's local git checkout is `/workspace/work/gen5-32-publication`.

Decision times are sums divided by actual decision counts, including forced
moves and opening leads, across unique physical root games in both auction
conditions. Forks, reused references and replayed prefixes are excluded. The
public dashboard reports each bot's overall, opening-lead and later-play means;
missing timing is not recorded as zero. These wall times include interface
overhead and depend on the host.

`ops/watch_gen5.py` checks the collector, BEN server and publisher each minute.
It restarts missing processes only after identity checks, respects an operator
`STOP`, preserves failures for inspection and bounds retries. A 2 GiB disposable
DDS memoization cache triggers a drain, cache compaction and resume; complete
records are untouched. A disk-space guard drains below 3 GiB free. Process IDs,
heartbeat, publisher status and watchdog status are in the run directory.

To drain collection, create `STOP` in the run directory; let active games finish.
To disable process recovery as well, create `WATCHDOG_STOP`. Inspect any failure
and verify no writer holds `.writer.lock` before manually restarting. With BEN
already listening on localhost:8087, a collector restart uses:

```sh
cd /workspace/Single-Dummy-Bridge
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 TF_NUM_INTRAOP_THREADS=1 \
TF_NUM_INTEROP_THREADS=1 XDG_CACHE_HOME=/workspace/work/gen5-cache \
/workspace/work/ben-venv/bin/python -u ops/gen5_runtime.py \
  --run /workspace/work/gen5-codex-32 --workers 3
```

The matching BEN config is `configs/ben-gen5-16.conf`; runtime dependencies are
in `configs/ben-round5-runtime-requirements.txt`. The BEN profile provenance pins
its models. On a new machine, restore the frozen run and runtime to matching
paths and supply the pinned BEN checkout/models before resuming.

only after entering that view. The 102 training-only deals are excluded even
from older rollups.
