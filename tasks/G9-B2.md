## Goal

Implement the rule filter with `FitScorer`'s interface so the engine can use it wherever it uses the scorer: `type_log_score(length, hon, seat, dealer, vulnerability, auction)` returns, per hand type, the sum over the seat's covered calls of `log m_t`; plus `compile_card(card) -> Settings` and `covered(...)`.

## Done when

A PR into `feature/gen9` with tests that show:
- On deals bid at all four seats by the rule bidder, every true hand scores 0 (it fits every covered call), for the precision and the standard settings and three sampled variants.
- Type-level evaluation equals evaluation on the concrete 13 cards for 10,000 random hands.
- The share of random hands a call excludes agrees with the meaning's stated ranges.
- No card: all zeros.
- Types scored per second, stated.

## Context

docs/gen9/architecture.md on feature/gen9, section 4.2 and interface I4. Base: `bridge_harness/rule_bidder.py`, `gen6_nets.FitScorer`, `system_nets.BoundFitScorer`.
