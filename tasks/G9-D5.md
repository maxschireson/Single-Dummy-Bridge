## Goal

Storage for `experience-v1`: collectors write one delta per board and player; a merge that is order-independent and detects a board counted twice; a snapshot frozen at each epoch boundary and named in every record played under it.

## Done when

A PR with tests (merge in any order gives the same store; a repeated delta is ignored; a snapshot is immutable).

## Context

Schema from G9-A2. bill and sam define what their statistics are; this task stores them without knowing their meaning.
