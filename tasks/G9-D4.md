## Goal

Player packages under `configs/players/`, an epoch manifest, and a runner that plays one epoch on one machine with the fork-free match machinery, then starts the next epoch with one player added and one retired, with no code change and no hand-written instruction.

## Done when

A PR with tests on a tiny epoch (dependency-light, like the two-board match in VALIDATION.md), and a demonstration with real bots.

## Context

docs/gen9/architecture.md on feature/gen9, section 6, interfaces I1, I3 and I7. The runner hands each player the table's player models through `meet(table)` (G9-A2).
