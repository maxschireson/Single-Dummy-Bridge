A small tool on this branch (`tools/workq.py`) for the protocol in README.md: `new`, `list`, `lease`, `renew`, `submit`, `resolve`, `release`, `block`, and `status` (regenerating STATUS.md). The lease is taken by a push that fails cleanly if someone else got there first. Header validation on every write.
